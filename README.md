# Little Postcard Studio

A cheerful, private postcard maker built with HTML, CSS and vanilla JavaScript.

## Run

Double-click index.html to open it in a modern browser.
No installation, account, API keys or internet connection required.

## Use

1. Choose a JPG, PNG or WebP photo up to 20 MB.
2. Write a message of up to 140 characters.
3. Choose Strawberry, Seaside or Matcha.
4. Download your 1200 × 800 PNG postcard.

Photos are processed only in your browser. They are never uploaded or saved
by the website. Photos are centered and cropped to fill the frame.

The preview and exported PNG use the same canvas.
System fonts and emoji can look different between operating systems.
